## Kann ich schon
- IntelliJ benutzt (Projektseminar), erste Erfahrung mit GitHub/Clonen
- Git eingerichtet (Name, E-Mail, `core.autocrlf=true`, `init.defaultBranch main`, GitHub-Login über Credential Manager)
- Repo lokal anlegen (`git init`) und mit GitHub verbinden (`git remote add origin`, `git push -u origin main`)
- Grundablauf: ändern → `git add` → `git commit -m` → `git push`
- Dateizustände: untracked (neu) / staged (im Paket) / modified (geändert, schon bekannt)
- `git status`, `git log --oneline` lesen (`HEAD -> main` = mein Stand, `origin/main` = letzter bekannter GitHub-Stand)
- Commit-Hash = eindeutige ID aus gesamtem Inhalt inkl. Message
- `git commit --amend` – nur vor dem Push!
- Gute Commit-Messages: kurz, Imperativ, beschreiben genau was passiert ("Initial commit" nur beim ersten)
- `.gitignore`: `*.endung`, `ordner/`, `dateiname`; Änderungen daran selbst committen
- Branch umbenennen: `git branch -m main`
